# Bare7a's Homebrew Tap

[BarSQL](https://github.com/Bare7a/BarSQL): a fast, native SQL client for PostgreSQL, MySQL, SQL Server, ClickHouse, SQLite and Turso.

```bash
brew install bare7a/tap/barsql
```

Already have BarSQL in Applications? Add `--adopt` to take over that copy.

BarSQL updates itself, so a plain `brew upgrade` only replaces it when the installed app is older than this tap's version.

BarSQL's release workflow writes `Casks/barsql.rb` from [`packaging/homebrew/barsql.rb`](https://github.com/Bare7a/BarSQL/blob/master/packaging/homebrew/barsql.rb), so change the cask there.
